What are emoji shortcodes?

A shortcode is a name between colons that an app swaps for an emoji: :tada: gives you 🎉. Slack, Discord, and GitHub understand them; macOS doesn’t, so Mail and Notes leave them as text.

Mojito makes every code here work in Mail, Notes, Messages, and your browser. Plain words work too: :yay finds 🥳.

Where do emoji shortcodes work?

  • Built in: Slack, Discord, GitHub, Linear, and Notion suggest matches as you type.
  • Terminal and code editors: Mojito stays out of these by default. Change that in SettingsExclusions.

Rather not install anything? See how to type emoji on a Mac and every emoji keyboard shortcut.

How to type emoji shortcodes on a Mac

  1. Install Mojito (free) and grant Accessibility and Input Monitoring.
  2. In any text field, type a colon and a few letters, like :+1.
  3. Press Return or Tab for the top match. Or finish the code (:+1:) to skip the picker.

Mojito also searches by meaning (:ghosting finds 👻). Symbols use two colons (::degree), and GIFs three (:::party).

Shortcode questions

Are shortcodes the same as emoji names?

No. The Unicode name for 😂 is “face with tears of joy”; :joy: is a nickname the apps settled on, which is why codes drift between apps.

Can I make my own shortcodes?

Slack’s custom emoji take any name you give them, in that workspace only. Mojito’s aliases map any word to any emoji, so :lgtm: can type 👍 in every Mac app.

What do the gitmoji codes mean?

Gitmoji is a convention for starting commit messages with an emoji code, like :sparkles: for a new feature or :bug: for a bug fix. The “Work and code” table above uses its meanings.

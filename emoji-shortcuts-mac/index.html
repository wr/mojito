Emoji keyboard shortcuts on Mac

Fn + E is the one to learn. Here’s every other emoji shortcut macOS has, the keys that work once the picker is open, and the shortcuts you can add yourself, in tables built for a quick glance.

By Wells Riley, who makes Mojito·Updated October 4, 2026·Tested on macOS 27

🌐fn E → 😀

or ⌃ Control ⌘ Command Space on a keyboard without Fn

What’s the emoji keyboard shortcut on a Mac?

Press Fn + E. On recent Macs the Fn key has a 🌐 globe printed on it. The emoji picker opens at your cursor: type to search, move with the arrow keys, and press Return to insert. If your keyboard has no Fn key, Control + Command + Space opens the same picker. Both work in any app and need no setup.

With Mojito, the fastest emoji shortcut is a colon: type :fire right where you’re writing and press Return. No panel, no mouse.

Make the 🌐 key open emoji on its own

  1. Open System SettingsKeyboard.
  2. Set Press 🌐 key to (it reads Press fn key to on keyboards without a globe) to Show Emoji & Symbols.

If it ever “stops working,” check this setting first: choosing a Dictation keyboard shortcut can change it without asking.

Type the word first

The least-known shortcut on the list. Type coffee, press Fn + E, and macOS offers ☕ and friends right there; pick one and it replaces the word. It’s the closest macOS gets to shortcodes on its own.

Forgot the keys? Use the Edit menu

Nearly every Mac app has EditEmoji & Symbols at the bottom of its Edit menu. Same picker, three clicks slower.

Emoji shortcuts you can add

macOS lets you add two kinds of shortcut yourself. An app adds the rest.

Text replacements for your favorites

In System SettingsKeyboardText Replacements…, click + and map a trigger like ;shrug to 🤷. Type the trigger and a space, and it swaps in. Replacements sync to your iPhone through iCloud, but they only fire in apps built on Apple’s text system, so not in Chrome, Slack, or VS Code. Step-by-step setup is in how to type emoji on a Mac.

Your own key for Emoji & Symbols

If neither built-in chord suits your hands, give the menu command a shortcut of your choosing:

  1. Open System SettingsKeyboardKeyboard Shortcuts…App Shortcuts and click +.
  2. Leave the application set to All Applications. For Menu title, type Emoji & Symbols exactly as it appears in the Edit menu.
  3. Click the shortcut field, press your keys, and click Done. If the combination is already taken, it won’t work until you change one of them.

Let ⌃⌘Space open Mojito instead

Mojito also has a full emoji browser: every emoji in a grid, with the cursor already in its search field. Type, arrow around, press Return. Out of the box it opens with ⌃ ⌥ Space. Click Replace System Picker in SettingsGeneral and ⌃ ⌘ Space and a tap of 🌐 open it instead of Apple’s panel, so your muscle memory carries over. Handing over the 🌐 key can take one log-out to settle, and the reset button gives Apple’s picker its shortcut back.

Which emoji shortcut should you use?

  • An emoji now and then: Fn + E. Nothing to set up.
  • A keyboard with no Fn key: ⌃ ⌘ Space.
  • You’d rather press one key: set 🌐 to Show Emoji & Symbols.
  • You know the word, not the emoji: type the word, then Fn + E.
  • The same five emoji, on your iPhone too: text replacements.
  • Emoji all day, and Slack codes already in your fingers: shortcodes with Mojito. The cheat sheet of popular emoji shortcodes is a good place to start.

In Slack, Discord, and GitHub, use their built-in : autocomplete. Mojito steps aside in those apps so the two don’t collide.

What if the shortcut does nothing?

Three usual suspects: the 🌐 key setting changed, another app claimed ⌃ ⌘ Space, or Secure Keyboard Entry is on. Terminal’s Secure Keyboard Entry option, some VPN clients, and background password managers can switch that on, and it blocks every emoji route, Mojito included. Shortcut questions

Why doesn’t Fn + E work on my external keyboard?

On many third-party keyboards, the Fn key is handled inside the keyboard and never reaches macOS, so the Mac can’t see the chord. Use Control + Command + Space, which works on any keyboard.

Can I change the emoji shortcut?

You can add your own, with the App Shortcuts trick above. You can also let Mojito take over ⌃ ⌘ Space and the 🌐 key so they open its keyboard-first emoji browser.

Is there a shortcut to type one specific emoji?

Not in macOS out of the box. A text replacement gets you one emoji per trigger you set up. Shortcodes get you all of them: :pizza:, :wave:, :100:, no setup per emoji.

What’s the emoji shortcut on Windows?

Win + . (period) or Win + ; opens the Windows emoji panel.

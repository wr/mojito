Emoji keyboard shortcuts on Mac

Fn + E is the one to learn. Here’s every other emoji shortcut macOS has, and the ones you can add.

By Wells Riley of Wells Workshop, maker of Mojito·Updated October 5, 2026·Tested on macOS 27

🌐fn E → 😀

or ⌃ Control ⌘ Command Space on a keyboard without Fn

What’s the emoji keyboard shortcut on a Mac?

Press Fn + E (the 🌐 key on recent Macs). The picker opens at your cursor: type to search, arrow to an emoji, and press Return.

No Fn key? Use Control + Command + Space. Both work in any app, with no setup.

Mojito makes a colon the fastest emoji shortcut: type :fire and press Return. No panel, no mouse.

Emoji shortcuts you can add

  • Text replacements. In System SettingsKeyboardText Replacements…, map ;shrug to 🤷. Syncs to your iPhone, but only works in Apple’s apps.
  • Your own key. In System SettingsKeyboardKeyboard Shortcuts…App Shortcuts, click +, keep All Applications, and type Emoji & Symbols as the menu title. Then press your keys and click Done.
  • Shortcodes, with Mojito. Type a colon, a few letters and Return in Mail, Notes, Messages, your browser and most other apps. Start with the popular emoji shortcodes.

Shortcut questions

Why doesn’t Fn + E work on my external keyboard?

On many third-party keyboards, the Fn key never reaches macOS. Use Control + Command + Space, which works on any keyboard.

What if the shortcut does nothing?

Usually the 🌐 key setting changed, another app claimed ⌃ ⌘ Space, or Secure Keyboard Entry is on. The full checklist is in Emoji picker not working on Mac?

Can I change the emoji shortcut?

You can add your own with App Shortcuts (above). Or use Mojito’s emoji browser: it opens with ⌃ ⌥ Space, and Replace System Picker in SettingsGeneral hands it ⌃ ⌘ Space and the 🌐 key.

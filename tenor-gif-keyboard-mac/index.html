Tenor GIF keyboard for Mac: what happened, and what works now

Tenor’s Mac app is long gone, and Google switched off the Tenor API on June 30, 2026. Here’s what works now.

By Wells Riley of Wells Workshop, maker of Mojito·Updated October 5, 2026·Tested on macOS 27

Is there a Tenor GIF keyboard for Mac?

Not anymore. Tenor’s own Mac app is gone, and since June 30, 2026, no other app can search Tenor either. You can still browse tenor.com, or use the GIF search in Messages, Slack, or Discord.

Mojito puts GIF search at your cursor: type :::party. Results come from KLIPY, co-founded by a Tenor co-founder.

What happened to Tenor?

Google bought Tenor in 2018, kept its site and apps, and has now shut the search API that other apps’ GIF buttons ran on.

WhenWhat happened

Tenor questions

Is Tenor shutting down completely?

No. Only the API other apps used is gone; tenor.com, Gboard, Tenor’s GIF Keyboard for iPhone and Android, Google Chat, and Google Messages keep Tenor’s GIFs.

Why did GIF search stop working in one of my apps?

If it still searched Tenor after June 30, 2026, it now gets an error back. Update the app, since most switched to GIPHY or KLIPY; if it still fails, the developer hasn’t moved yet.

Will old Tenor GIF links keep working?

For now, mostly: files on media.tenor.com still load as of October 4, 2026, but Google hasn’t promised to keep them up. Download any you want to keep.

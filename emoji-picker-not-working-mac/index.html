Emoji picker not working on Mac? Here’s the fix

Three routes open the same picker, and which one fails tells you why. Run the 30-second test, then work down the fixes.

By Wells Riley, who makes Mojito·Updated October 5, 2026·Tested on macOS 27

🌐fn E → 😀

Nothing? Also try ⌃ Control ⌘ Command Space and Edit › Emoji & Symbols. Which one fails tells you why.

Why won’t the emoji picker open on my Mac?

Usually one of three things: the 🌐 key was reassigned, an app switched on Secure Keyboard Entry, or another app took the shortcut.

Mojito lets you type :smile and press Return for 😄, without Apple’s picker. Secure Keyboard Entry blocks it too.

The 30-second test

In a plain text field (a new TextEdit document is ideal), try Fn + E, ⌃ ⌘ Space, and EditEmoji & Symbols:

1. The 🌐 key was switched to something else

You’ll know it’s this if tapping 🌐 does nothing or changes your keyboard language, while Fn + E still works.

  1. Open System SettingsKeyboard.
  2. Set Press 🌐 key to (or Press fn key to) to Show Emoji & Symbols.
  3. Use 🌐 for Dictation too? Choosing a Dictation shortcut can change this setting, so give Dictation one without 🌐 in KeyboardDictationShortcut, then set the key back.

2. Secure Keyboard Entry is on

You’ll know it’s this if nothing opens the picker, not even the Edit menu, in any app, and your text expander has gone quiet too.

  1. Check the usual suspects: TerminalSecure Keyboard Entry (iTerm2 has the same option), Cisco AnyConnect (now Cisco Secure Client), Webroot, and password managers.
  2. Not sure? In Terminal, run ioreg -l -w 0 | grep SecureInput. If it prints nothing, Secure Input is off; skip to fix 3.
  3. Otherwise, find the number after "kCGSSessionSecureInputPID"=, say 1234, and run ps -p 1234 -o comm= to name the app.
  4. Quit that app, or turn off its secure-entry setting, and press Fn + E again. If it’s loginwindow, log out and back in (fix 5).

3. Another app took the shortcut

You’ll know it’s this if ⌃ ⌘ Space does nothing, or opens something else, while Fn-E and the Edit menu still work.

  1. Quit apps that hand out hotkeys one at a time (Raycast, Alfred, BetterTouchTool, Keyboard Maestro, window managers, IDEs), pressing ⌃⌘Space after each. System Settings won’t list their hotkeys.
  2. Change the hotkey in whichever app brings the picker back.
  3. If Mojito’s Replace System Picker option is on, the reset button next to Emoji Browser shortcut in its SettingsGeneral undoes it.

If Fn-E is the one that fails

Many third-party keyboards and remappers like Karabiner-Elements handle Fn themselves, so macOS never sees it (Logitech says Apple’s Fn/Globe shortcuts aren’t supported). Use ⌃⌘Space instead.

4. It’s opening where you can’t see it

You’ll know it’s this if the picker works in a normal window but not in full screen, or turns up on your other display.

  1. Leave full screen with ⌃ ⌘ F, or look on your other display. If that display is gone, plug it back in once.
  2. Open the picker. If you get the big Character Viewer, click the button in its top-right corner to shrink it to the small picker (the two pickers).
  3. Go back to full screen. The small picker sits at your cursor, so it should appear there.

5. Log out and back in, or restart

You’ll know it’s this if nothing above fits.

  1. Log out and back in from the Apple menu. This clears a Secure Input lock stuck on loginwindow.
  2. Still broken? Restart.
  3. If the picker works in safe mode, which skips login items, turn items in System SettingsGeneralLogin Items & Extensions back on a few at a time to find the culprit.

Or skip the system picker

Mojito works the way Slack does: type a colon and a few letters in any app, and matches appear at your cursor, using Slack and GitHub’s codes (cheat sheet). It never touches the 🌐 key, ⌃⌘Space, or the Character Viewer, so fixes 1, 3, and 4 can’t happen to it.

More picker questions

Why does the picker work everywhere except one app?

Password fields block it on purpose. Otherwise the app may have its own secure-entry option on, be in full screen (fix 4), or draw its own text fields, as many games and remote-desktop windows do.

Did macOS 27 change the emoji shortcuts?

No: Fn + E, ⌃ ⌘ Space, and the 🌐 setting work as before. The picker just got Apple’s glass look and, on Macs with Apple Intelligence, a Genmoji button in its top-right corner.

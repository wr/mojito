How to type ⌘, ⌥, ⇧ and other Mac key symbols

None of the Mac’s modifier symbols has a keystroke of its own, which is awkward when you’re writing instructions about keystrokes. Here’s the fastest way to type each one, what Unicode calls them, and the order Apple lists them in.

By Wells Riley, who makes Mojito·Updated October 4, 2026·Tested on macOS 27

::cmd → ⌘

No built-in keystroke types ⌘. That’s Mojito’s shortcode; the built-in routes are below.

How do I type the Command symbol (⌘) on a Mac?

No key combination types ⌘; macOS doesn’t have one. The quickest built-in route is the Character Viewer: press Fn + E, expand the panel, add Technical Symbols to its sidebar (a one-time step), and double-click ⌘. If you type these often, add the Unicode Hex Input source and type Option + 2318 instead.

The same goes for ⌥, ⇧, ⌃ and the rest. They’re printed on your keys and shown in every menu, yet nothing on the keyboard types them, even though the Option layer is full of other symbols like π and ≠ or € and £.

With Mojito, you type ::cmd, ::option, ::shift, or ::control in any app. The codes are the key names, so there’s nothing to look up.

The Unicode names also explain why these are hard to search for: as far as Unicode is concerned, ⌘ is a “place of interest sign” and ⌃ is an “up arrowhead.” The Fn key has no character at all; Apple draws its 🌐 as an icon, so most people write “Fn” or use the 🌐 emoji.

The people who need these are mostly writing for someone else: help articles, support replies, release notes, a shortcut cheat sheet for a new teammate. The glyphs match what Mac users see in every menu, and ⌥⌘⎋ scans faster in a table than Option-Command-Escape. Apple’s own support articles spell shortcuts out in words, so for running prose, words are just as correct.

What order do the modifier symbols go in?

Apple’s Human Interface Guidelines say to list modifier keys in this order: Control, Option, Shift, Command. In glyphs that’s ⌃ ⌥ ⇧ ⌘, with the main key last. Apple’s built-in shortcuts follow it:

  • ⌃⌘Q locks your screen.
  • ⌥⌘⎋ opens Force Quit.
  • ⌥⇧⌘V pastes and matches the surrounding style.
  • ⌃⌘Space opens the Character Viewer.

Writing ⌘⇧V instead isn’t wrong, exactly, but it won’t match the menus your reader is looking at.

5 ways to type ⌘ and the other key symbols

  1. The Character Viewer: press Fn + E (or Control + Command + Space) to open the same panel as the emoji picker, and click the expand button in its top-right corner. The key symbols aren’t in the sidebar by default: open the Action menu, choose Customize List, and turn on Technical Symbols. ⌘, ⌥, ⇧, ⌃, ⎋, ⏎, ⌫ and the rest are now one click away; double-click to insert, or add the ones you use to Favorites.
  2. Unicode Hex Input: add it in System SettingsKeyboardText InputEdit… (click + and search for it), and switch to it from the Input menu in the menu bar. Hold Option and type the code from the table: 2318 for ⌘, 2325 for ⌥, 21E7 for ⇧, 2303 for ⌃. Switch back to your usual layout when you’re done.
  3. A text replacement: in System SettingsKeyboardText Replacements…, map ;cmd to ⌘, ;opt to ⌥, and so on. They sync to your iPhone, but only fire in apps built on Apple’s text system, so not in Chrome, Slack, or VS Code.
  4. An HTML entity: on a web page, &#8984; is ⌘, &#8997; is ⌥, &#8679; is ⇧, and &#8963; is ⌃.
  5. A shortcode: with Mojito installed, type ::cmd anywhere and press Return, or type ::cmd:: to drop it in without the picker.

The Apple logo is the one symbol with a key

Shift + Option + K types , on both the US and British layouts. It lives at U+F8FF, in a part of Unicode set aside for private use, where each company can put whatever it likes. Only Apple’s fonts draw an apple there, so on Windows, Android, and many web fonts it turns into an empty box or something else entirely. Use it in notes to yourself and messages to other Apple users, not on anything public. In Mojito it’s ::apple; with one colon, :apple: is 🍎.

Where does the ⌘ symbol come from?

In 1983, the Macintosh team showed a little Apple logo next to every menu item that had a keyboard shortcut. Steve Jobs decided there were too many Apples on the screen. Susan Kare, the Mac’s icon designer, leafed through an international symbol dictionary and found a looped square used in Sweden to mark places of interest. Swedish readers have since pointed out it’s a road-sign symbol for sights and historic sites rather than campgrounds, but the name stuck: Unicode still calls U+2318 the place of interest sign, and lists “command key” as its other name.

More key symbol questions

What does ⌥ mean, and why does my keyboard say “alt”?

⌥ is the Option key. Apple stopped printing “alt” on it around 2017, so older Mac keyboards show both, and Apple’s docs still say “Option (or Alt).” On a Windows keyboard plugged into a Mac, Alt does Option’s job and the Windows key (or Ctrl) does Command’s.

Is ⌃ the same as the caret (^)?

No. ⌃ (U+2303) is the Control key symbol; ^ is the caret on Shift + 6. You’ll see ^C in Terminal and Unix docs, which is a different way of writing the same Control-C.

How do I show keyboard shortcuts in Markdown or HTML?

Wrap each key in a <kbd> tag: <kbd>⌘</kbd><kbd>C</kbd>. Most Markdown renderers pass raw HTML through, so it works in both.

Can I type ⌘ on an iPhone or iPad?

Not from the keyboard. Make a text replacement on your Mac (;cmd → ⌘) and it syncs to your iPhone and iPad through iCloud.

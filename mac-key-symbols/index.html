How to type ⌘, ⌥, ⇧ and other Mac key symbols

The Character Viewer types ⌘, ⌥ and ⇧ in any app. Here’s how, four other ways, and the order Apple lists them in.

By Wells Riley, who makes Mojito·Updated October 5, 2026·Tested on macOS 27

::cmd → ⌘

No built-in keystroke types ⌘. That’s Mojito’s shortcode; the built-in routes are below.

How do I type the Command symbol (⌘) on a Mac?

Press Fn + E, click the expand button (top right), and double-click ⌘ under Technical Symbols. The first time, turn that category on under the Action menu’s Customize List.

No key combination types ⌘, ⌥, ⇧ or ⌃, even though the Option layer has π and ≠ and € and £.

Mojito lets you type ::cmd, ::option or ::shift in any app. The codes are the key names.

Other ways to type them

  • Unicode Hex Input. Worth it if you type them often. Add it in System SettingsKeyboardText InputEdit…, switch to it, and hold Option while typing the code from the table: 2318 is ⌘.
  • Text replacement. In System SettingsKeyboardText Replacements…, map ;cmd to ⌘. Syncs to your iPhone, but only works in Apple’s apps.
  • HTML entity. On a web page, &#8984; is ⌘ and &#8997; is ⌥.
  • Shortcode. With Mojito, type ::cmd and press Return, or type ::cmd:: to skip the picker.

Copy a glyph from the table if you only need it once. The Fn key has no character, so write “Fn” or use the 🌐 emoji.

The Apple logo is the one symbol with a key

Shift + Option + K types . It’s a private-use character only Apple’s fonts draw, so on Windows, Android and many web fonts it shows up as a box. Use it with other Apple users, not on anything public.

What order do the modifier symbols go in?

Apple’s Human Interface Guidelines say ⌃ ⌥ ⇧ ⌘ (Control, Option, Shift, Command), with the main key last:

  • ⌃⌘Q locks your screen.
  • ⌥⌘⎋ opens Force Quit.
  • ⌥⇧⌘V pastes and matches the surrounding style.

More key symbol questions

What does ⌥ mean, and why does my keyboard say “alt”?

⌥ is the Option key. Apple stopped printing “alt” on it around 2017, so older Mac keyboards show both.

Is ⌃ the same as the caret (^)?

No. ⌃ (U+2303) is the Control key symbol and ^ is the caret on Shift + 6, though ^C in Terminal means the same Control-C.

Can I type ⌘ on an iPhone or iPad?

Not from the keyboard. Make a text replacement on your Mac (;cmd → ⌘) and it syncs to your iPhone and iPad.

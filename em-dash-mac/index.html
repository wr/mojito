How to type an em dash on a Mac (—)

Shift-Option-Hyphen, in any app. Here’s that, the en dash, and how to stop -- turning into a dash on its own.

By Wells Riley, who makes Mojito·Updated October 5, 2026·Tested on macOS 27

⇧shift ⌥option -hyphen → —

What’s the em dash shortcut on a Mac?

Press Shift + Option + Hyphen (the key right of 0). Leave out Shift for the shorter en dash (–).

It works in every app because it’s part of the keyboard layout, not an app feature. That’s the US layout; other layouts can put it elsewhere.

Mojito lets you type ::em and press Return instead, on any keyboard layout.

Other ways to type it

  • Two hyphens. Type -- in Apple’s apps (TextEdit, Notes, Mail, Messages) and Smart Dashes turns it into —. Doesn’t work in Chrome, Slack, or VS Code.
  • Character Viewer. Press Fn + E, click the expand button (top right), search em dash, and double-click it.
  • Text replacement. In System SettingsKeyboardText Replacements…, map ;em to —. Syncs to your iPhone, but only works in Apple’s apps.
  • Shortcode. With Mojito, type ::em_dash in any app, or just ::em and pick it from the list.

The most common slip is a hyphen in a range (Mon-Fri). Use the en dash: ⌥ -.

How do I stop -- turning into —?

That’s Smart Dashes, and it gets in the way when you’re typing code or a flag like --force.

  • One app: EditSubstitutionsSmart Dashes
  • Every app: turn off Use smart quotes and dashes in System SettingsKeyboardText InputEdit…. It turns off smart quotes too.
  • Pages, Numbers, Keynote: PagesSettingsAuto-Correction
  • Word: WordPreferencesAutoCorrectAutoFormat As You Type

How do I type an em dash on iPhone?

On the 123 keyboard, press and hold the hyphen key, then slide to —.

More dash questions

Should there be spaces around an em dash?

AP style (news) uses spaces ( — ); Chicago and most books don’t (—). Pick one and stay consistent.

What’s the HTML code for an em dash?

&mdash; for — and &ndash; for –.

How to type currency symbols on a Mac (€, £, ¥ and more)

€ is Shift-Option-2 on a US keyboard, Option-2 on British. Here’s every currency key, and how to type ₹, ₩, ₿ and the rest.

By Wells Riley of Wells Workshop, maker of Mojito·Updated October 5, 2026·Tested on macOS 27

⇧shift ⌥option 2 → €

US layout. On a British keyboard it’s ⌥ 2.

How do I type the euro sign on a Mac?

On a US keyboard, press Shift + Option + 2. On a British keyboard it’s Option + 2.

It works in any app because it’s part of your keyboard layout, so switching layouts moves it, whatever your keycaps say.

Mojito lets you type ::euro and press Return instead, on any layout, including signs with no key.

Other ways to type them

  • Character Viewer. Press Fn + E to open the emoji picker, click the expand button (top right), and choose Currency Symbols. ₿ isn’t there, so search for it.
  • Unicode Hex Input. Add it in System SettingsKeyboardText InputEdit…, switch to it, then hold Option and type a code from the table below: 20B9 for ₹.
  • Text replacement. In System SettingsKeyboardText Replacements…, map ;inr to ₹. Syncs to your iPhone, but only works in Apple’s apps.
  • ABC – India layout. Same letters as US, with ₹ on ⌥ 4. The backtick key types ₹ too, so a real backtick needs Option.
  • Shortcode. With Mojito, type ::euro in any app and press Return.

More currency questions

Why does Option-3 type # instead of £?

You’re on the British layout, where £ is Shift + 3 and # moved to Option + 3. The Input menu in your menu bar shows which layout is active.

How do I type € on a Windows keyboard plugged into a Mac?

The Alt key does Option’s job, so on the US layout it’s Shift + Alt + 2.

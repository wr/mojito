How to type currency symbols on a Mac (€, £, ¥ and more)

On a US keyboard, € is Shift-Option-2. On a British one it’s Option-2. Here’s every currency sign that has a key, why the keys move when your layout changes, and the quickest way to type ₹, ₩, ₿ and the rest that have no key at all.

By Wells Riley, who makes Mojito·Updated October 4, 2026·Tested on macOS 27

⇧shift ⌥option 2 → €

How do I type the euro sign on a Mac?

On a US Mac keyboard, press Shift + Option + 2 to type €. On a British keyboard it’s one key fewer: Option + 2. The pound sign is Option + 3 on US and Shift + 3 on British, and the yen sign is Option + Y on both. They all work in any app, with no setup.

They work everywhere because the symbols belong to your keyboard layout, the map macOS uses to turn a key press into a character. That’s also why they differ by country: switch layouts and the map changes, whatever is printed on the keycaps.

With Mojito, you type ::euro, ::pound, or ::yen and press Return. The codes are the same on every layout, and they cover the currencies with no key, like ::indian_rupee_sign for ₹.

That’s the whole list. Every other currency sign needs one of the routes further down. One more trap for American readers: when someone says “pound sign” they sometimes mean #, the pound key on a phone. That’s plain Shift + 3 on a US keyboard.

Why are the keys different on a British keyboard?

A Mac doesn’t read the symbols printed on your keys. The keyboard reports which key you pressed, and the layout chosen in System Settings decides what character that means. Apple’s British layout puts £ on Shift + 3 because that’s where British keyboards print it, which bumps # to Option + 3. The euro takes Option + 2, so ™, which lives there on US, moves to Shift + Option + 2.

It isn’t only currency. On British, the per mille sign ‰ moves from ⇧ ⌥ R to ⇧ ⌥ E, and much of the Shift-Option layer becomes accented capital letters. So if a shortcut from a US guide (the ™ shortcut, say) types the wrong thing, check your layout before anything else.

How to check which layout you’re using

  1. Open System SettingsKeyboardText InputEdit…. The list on the left shows every layout you’ve added.
  2. Turn on Show Input menu in menu bar. The menu bar now shows which layout is active, and you can switch from there.
  3. In that Input menu, choose Show Keyboard Viewer. Hold Option, or Shift and Option, and the on-screen keys change to show exactly what your layout types.

The keyboard map above always shows the US layout. The Keyboard Viewer shows yours.

Which currency symbols have no Mac shortcut?

On the US and British layouts, none of these has a key. Mojito’s codes for them come straight from each sign’s Unicode name, which makes them long but guessable.

You rarely type a whole code: ::bitcoin, ::won, ::ruble, and ::naira each put the right sign at the top of the picker. Two quirks. ::rupee lists ₨, Unicode’s older and unofficial rupee sign, just above ₹. And Unicode spells shekel “sheqel,” so ::sheqel finds ₪ where ::shekel finds nothing.

Most national layouts carry their own sign. Turkish Q puts ₺ on ⌥ T, Hebrew puts ₪ on ⇧ 7, and 2-Set Korean types ₩ from the backtick key. They move your letters too, so they only make sense if you write in that language. The useful exception is ABC – India: letters and numbers stay exactly where US has them, and ⌥ 4 types ₹. The catches are that the backtick key types ₹ as well, so a real backtick needs Option (programmers will notice), and most of the US Option-layer symbols give way to transliteration accents.

The new Saudi riyal sign

Unicode 17 added a sign for the Saudi riyal, ⃁ (U+20C1). The system font in macOS 27 draws it, and Mojito finds it there as ::saudi_riyal_sign, or just ::riyal. Font support is still catching up elsewhere: on older systems, and in plenty of web fonts, it can show up as an empty box, so check how it renders before it goes on an invoice. Unicode 18 has since added signs for the UAE dirham, the Omani rial, and the Maldivian rufiyaa, and macOS 27 doesn’t draw those yet.

6 ways to type a currency symbol on a Mac

  1. The Option shortcut: fastest for €, £, ¥, ¢, and ƒ, in every app. One exception: Terminal sends Option to the shell instead of typing symbols when Use Option as Meta key is on in TerminalSettingsProfilesKeyboard.
  2. The Character Viewer: press Fn + E (or Control + Command + Space) to open the same panel as the emoji picker, click the expand button in its top-right corner, and choose Currency Symbols in the sidebar. Double-click a sign to insert it. ₿ isn’t in that list, so search for it by name.
  3. Unicode Hex Input: add it in System SettingsKeyboardText InputEdit… (click + and search for it), switch to it, then hold Option and type the code from the table. Option + 20B9 types ₹.
  4. A text replacement: in System SettingsKeyboardText Replacements…, map something like ;inr to ₹. It syncs to your iPhone, but it only fires in apps built on Apple’s text system, so not in Chrome or Slack.
  5. A layout with the key: ABC – India for ₹, as above, or your own language’s layout.
  6. A shortcode: with Mojito installed, type ::euro in any text field and press Return. A picker appears as you type, best match on top.

More currency questions

Why does Option-3 type # instead of £?

You’re on the British layout, where £ is Shift + 3 and # moved to Option + 3. US does the opposite. The Input menu in your menu bar shows which layout is active.

How do I type € on a Windows keyboard plugged into a Mac?

The Alt key does Option’s job, so on the US layout it’s Shift + Alt + 2. Every Option shortcut on this page works the same way with Alt.

Do these shortcuts work in Word and Google Docs?

Yes. They’re part of the keyboard layout, so they work in Word, and in Google Docs in any browser. Docs also has InsertSymbolsSpecial characters, where you can search, enter a Unicode value, or draw the sign you’re after.

What’s the HTML code for the euro sign?

&euro; or &#8364; for € (U+20AC). The pound is &pound;, the yen &yen;, the cent &cent;, and ₹ is &#8377;.

Why does :euro: give me 💶 instead of €?

In Mojito, one colon searches emoji and two search symbols. :euro: is the banknote emoji, while ::euro_sign is the currency sign. The same goes for :pound: 💷 and ::pound £.

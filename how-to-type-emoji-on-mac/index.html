How to type emoji on a Mac

Every Mac ships with an emoji picker that’s one shortcut away. Here are seven ways to reach for an emoji, from the Edit menu nobody remembers to typing :tada: like you would in Slack.

By Wells Riley, who makes Mojito·Updated October 4, 2026·Tested on macOS 27

🌐fn E → 😀

or ⌃ Control ⌘ Command Space on any keyboard

What’s the emoji shortcut on a Mac?

Press Fn + E. On Macs from the last few years the Fn key has a 🌐 globe on it, bottom left. The emoji picker opens right at your cursor: start typing to search (pizza, party, thumbs), then click an emoji, or use the arrow keys and Return. If your keyboard has no Fn key, Control + Command + Space opens the same picker. Neither needs any setup.

With Mojito, you skip the picker. Type :tada anywhere and press Return for 🎉, the same codes Slack, Discord, and GitHub use.

1. Fn + E: Apple’s emoji shortcut

Click into any text field and press Fn + E. This is the shortcut Apple documents today, and it works on the built-in keyboard and on any Apple keyboard with an Fn or 🌐 key. The picker remembers your recent emoji, so the ones you use most sit at the top.

2. Control + Command + Space

The original shortcut, still fully supported. It’s the one to use on a third-party keyboard that has no Fn key, and it’s handy if Fn + E is awkward for your hand.

3. Make the 🌐 key open emoji on its own

  1. Open System SettingsKeyboard.
  2. Set Press 🌐 key to (it says Press fn key to on older keyboards) to Show Emoji & Symbols.
  3. Tap 🌐 by itself in any text field.

One catch: picking a new Dictation shortcut can quietly change this setting, which is why the Globe key sometimes “stops working.” If it does, come back here and set it again.

4. Type a word, then press Fn + E

Since macOS Sonoma, you can type the word first. Write heart or coffee, press Fn + E, and macOS offers matching emoji; pick one and it replaces the word. If nothing matches, you get the regular picker instead. It’s the closest thing to shortcodes macOS has built in, and few people know it’s there.

5. Edit › Emoji & Symbols

Nearly every Mac app has EditEmoji & Symbols at the bottom of its Edit menu. It opens the same picker. Slow, but it’s there when the shortcut has slipped your mind. Mail and Messages also have an emoji button right in the window.

6. Text replacements

  1. Open System SettingsKeyboardText Replacements….
  2. Click +. Under Replace type a trigger like ;tada; under With, press Fn + E and pick 🎉.
  3. Type ;tada followed by a space in TextEdit, Notes, Mail, or Messages.

Replacements sync to your iPhone and iPad through iCloud, which is lovely. Two limits: each emoji needs its own rule, and they only fire in apps built on Apple’s text system, so not in Chrome, Slack, or VS Code. (Skip omw as a trigger; macOS already uses it for “On my way!”)

7. Shortcodes, in any app

If you use Slack, Discord, GitHub, or Linear, your fingers already know this one: a colon, a few letters, Return. Mojito is a free app that brings that to the whole Mac. Type :fire and a small picker appears at your cursor with 🔥 on top. Press Return, or type the closing colon (:fire:) to drop it in without looking.

It searches by meaning, not only by official name. :ghosting finds 👻, :yay brings up 🥳, 🙌, and 🎉, and the results learn which emoji you actually use.

Skin tones, favorites, and other picker tricks

  • Skin tone: in the picker, click and hold an emoji that has skin-tone variants, then choose one. macOS remembers your choice per emoji, not globally.
  • Bigger picker: click the expand button in the top-right corner for the full Character Viewer, with categories, a larger search, and symbols beyond emoji. Click it again to shrink back.
  • Favorites: in the expanded viewer, select an emoji and click Add to Favorites.
  • Tidy up: the expanded viewer’s Action menu can customize the category list and clear Frequently Used.
  • Genmoji: on Macs with Apple Intelligence, the Genmoji button in the picker’s top-right corner makes a custom emoji from a description. They’re saved alongside your stickers.

What’s new with emoji on macOS

macOS Tahoe 26.4 (March 2026) added Emoji 17.0, bringing the total to 3,953: Distorted Face, Fight Cloud, Ballet Dancers, Orca 🫍, Hairy Creature, Trombone 🪊, Landslide, and Treasure Chest 🪎, plus skin-tone variants. If you send one to someone on an older system, they’ll see an empty box. The next set, Emoji 18.0 (pickle, lighthouse, a cracking face), was finalized in September 2026 and usually reaches Apple devices the following spring.

macOS 26 and 27 restyled the picker with Apple’s new glass look, but the shortcuts and settings haven’t changed, so everything on this page applies from macOS 14 through 27.

The picker won’t open?

Usually it’s one of three things: the 🌐 key setting changed, another app grabbed the shortcut, or something has turned on Secure Keyboard Entry (Terminal, a VPN client, or a password manager can do this, and it blocks every emoji route). The full checklist is in Emoji picker not working on Mac?

Common questions

Can I type emoji without touching the mouse?

Yes. In the built-in picker, type to search, use the arrow keys, and press Return. With shortcodes it’s shorter still: :fire, Return, keep writing.

Why does pressing Fn start Dictation instead?

The Press 🌐 key to setting is set to Start Dictation, often because a Dictation shortcut was chosen at some point. Change it back in System SettingsKeyboard, or just use Fn + E, which works regardless of that setting.

Do emoji look the same on Windows and Android?

Each platform draws its own artwork, so details differ, and a brand-new emoji can show up as a box on a system that hasn’t caught up yet. The character you send is standard Unicode either way.

Can I set a default skin tone for every emoji?

Not in macOS: it remembers a tone per emoji, after you pick it once. Mojito has a single default skin tone setting that applies to everything you type through it.

How to type a check mark on a Mac (✓)

No key types ✓, and the Option-V tip going around types √, a square root. Here’s how to get a real one in any app.

By Wells Riley of Wells Workshop, maker of Mojito·Updated October 5, 2026·Tested on macOS 27

::check_mark → ✓

macOS has no shortcut for ✓. ⌥ V types √, a square root.

How do I type a check mark on a Mac?

There’s no keyboard shortcut. Use the Character Viewer: press Fn + E, click the expand button (top right), search check, and double-click ✓.

Unlike °, ©, or ™, it isn’t on the US, British, German, French, Spanish, or Italian layouts. And Option + V isn’t it: that’s √.

Mojito lets you type ::tick and press Return for ✓, or :white_check_mark: for ✅.

Other ways to type it

  • Emoji picker. For ✅, ✔️, or ☑️, open the emoji picker with Fn + E and type check straight away.
  • Unicode Hex Input. Add it in System SettingsKeyboardText InputEdit… (click +), switch to it, then hold Option and type 2713. It’s a whole keyboard layout, so switch back when you’re done.
  • Text replacement. In System SettingsKeyboardText Replacements…, map ;check to ✓. Syncs to your iPhone, but only works in Apple’s apps.
  • Shortcode. With Mojito, type ::tick or ::check_mark in any app. Just ::check lists the whole family (☑ ☐ ✓ ✔).

Why isn’t Option-V a check mark?

⌥ V types √, the square root sign. It looks like a tick in many fonts, but a search for ✓ won’t find it, and a spreadsheet counting ✓ cells will skip it. Already used it? Find and Replace √ with ✓.

  • ✓ is the safe default. It’s plain text, so it matches the words around it.
  • ✅ is louder. Save it for chat and status updates.
  • ✔ can turn into the ✔️ emoji in some apps. Mojito keeps it as text.

Wanted a checkbox you can tick?

  • Notes: press ⇧ ⌘ L to make a checklist.
  • Reminders: every item already has one.
  • Google Docs: pick Checklist from the list buttons in the toolbar.
  • Plain text: use ☐ and ☑ (::checkbox and ::checkbox_checked in Mojito).

How do I type a check mark on iPhone?

Search check on the emoji keyboard for ✅. For a plain ✓, use a text replacement; ones you set up on your Mac sync over.

More check mark questions

Is a tick the same thing as a check mark?

Yes, same character (U+2713): British English says tick, American English says check mark. Mojito answers to both ::tick and ::check_mark.

What’s the HTML code for a check mark?

&check; or &#10003; for ✓, and &#10004; for ✔. In CSS content, a ✓ is "\2713".

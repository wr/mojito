How to type a check mark on a Mac (✓)

There’s no key for it, and the Option-V shortcut that keeps getting passed around types √, a square root. Here’s how to get a real ✓ in any app, which check mark to pick, and what to do when you actually wanted a box you can tick.

By Wells Riley, who makes Mojito·Updated October 4, 2026·Tested on macOS 27

::check_mark → ✓

macOS has no shortcut for ✓. ⌥ V types √, a square root.

How do I type a check mark on a Mac?

There’s no keyboard shortcut for ✓ on a Mac. The quickest built-in route is the Character Viewer: press Fn + E (or Control + Command + Space), click the expand button in the top-right corner, search for check, and double-click ✓. For the green ✅ emoji, skip the expanding: Fn + E, type check, click it. Don’t use Option + V: that’s √, the square-root sign.

Unlike °, ©, or ™, the check mark never made it onto a Mac keyboard layout. It isn’t on US English, and it isn’t on British, German, French, Spanish, or Italian either. So every method below does one of three things: picks it from a list, types its code, or expands a shortcut into it.

With Mojito, type ::tick and press Return for ✓, or ::check_mark:: to drop it in without the picker. The green emoji is :white_check_mark: ✅.

5 ways to type a check mark on a Mac

  1. The Character Viewer: press Fn + E to open the emoji picker, click the expand button in the panel’s top-right corner, search for check, and double-click ✓. The heavy check mark (✔) and the ticked box (☑) are in the same results. Select the one you use and click Add to Favorites, and next time it’s one click away.
  2. The emoji picker: for ✅, ✔️, or ☑️, press Fn + E and type check straight away. The compact picker searches emoji as you type; click the one you want.
  3. Unicode Hex Input: the nearest thing to a real shortcut. Open System SettingsKeyboardText InputEdit…, click +, search for Unicode Hex Input, and click Add. Switch to it from the Input menu in the menu bar, then hold Option and type 2713 for ✓ (2714 for ✔, 2611 for ☑). It’s a whole keyboard layout, so switch back when you’re done. Some people report it turning up as the login screen’s keyboard after updating to macOS Tahoe, so remove it if you only needed it once.
  4. A text replacement: in System SettingsKeyboardText Replacements…, click + and map something like ;check to ✓ (paste it in from this page). It syncs to your iPhone through iCloud, but it only fires in apps built on Apple’s text system, so not in Chrome, Slack, or VS Code.
  5. A shortcode: with Mojito installed, type ::tick or ::check_mark in any text field and press Return. Typing just ::check lists the whole family (☑ ☐ ✓ ✔) so you can pick one.

Why isn’t Option-V a check mark?

Because it’s a square root. ⌥ V types √ (U+221A, SQUARE ROOT), a math operator that happens to look like a tick in a lot of sans-serif fonts. It gets recommended all over the internet, and it works right up until something has to treat it as a check mark: search a document for ✓ and it won’t match, and a spreadsheet counting ✓ cells will skip it.

If you’ve been using it for a while, one pass of Find and Replace (√ to ✓) cleans up the backlog. The real √ belongs with the rest of the math symbols.

Which check mark should I use?

Unicode has a whole drawer of them. These are the ones worth knowing, plus their opposites and the impostor:

MarkNameUnicodeMojitoGood for
✓Check markU+2713::check_markPlain text, lists, documents
✔Heavy check markU+2714::heavy_check_markA bolder tick
✅Check mark button (emoji)U+2705:white_check_mark:Chat, status updates, “done”
☑Ballot box with checkU+2611::checkbox_checkedA ticked box in plain text
✗Ballot XU+2717::x_markThe opposite of ✓
❌Cross mark (emoji)U+274C:x:The opposite of ✅
√Square rootU+221A::sqrtMath only. This is what ⌥V types

✓ is the safe default. It’s plain text, so it takes the color and size of the words around it and looks right in a document, an email, or a spreadsheet cell, and it has no emoji version to turn into. ✅ is louder and more casual; it belongs in chat and status updates. ✔ sits in between, but it’s the one most likely to surprise you: it has an emoji form, so depending on the app it can show up as black text or as ✔️. Mojito inserts it with the text-style variation selector so it stays text. If you want the emoji on purpose, use :heavy_check_mark:, or :ballot_box_with_check: for ☑️; the rest are in the emoji shortcode cheat sheet.

Wanted a checkbox you can actually tick?

A typed ✓ is just a character. For a to-do list, most apps have real checkboxes that toggle when you click them:

  • Notes: press ⇧ ⌘ L to make a checklist, then click an item’s circle to tick it off.
  • Reminders: every item already has one. Nothing to type.
  • Google Docs: pick Checklist from the list buttons in the toolbar.
  • Pages: no clickable boxes, but you can make ✓ the bullet. In the Format sidebar’s Style tab, open Bullets & Lists, choose Text Bullets, then double-click the Bullet field and type or paste ✓.
  • Markdown: on GitHub and in many Markdown editors, - [ ] and - [x] render as checkboxes.

Where only plain text will do, like an email or a commit message, use ☐ and ☑: search ballot in the Character Viewer, or type ::checkbox and ::checkbox_checked in Mojito.

How do I type a check mark on iPhone or iPad?

There’s no check mark key there either. Tap the emoji key and search check for ✅, ✔️, or ☑️. For a plain ✓, use a text replacement: set one up on your Mac and it syncs over, or add it on the iPhone in SettingsGeneralKeyboardText Replacement, with ✓ as the phrase and something like ;check as the shortcut.

More check mark questions

Is there a check mark in the Mac’s emoji picker?

Yes, as emoji: ✅, ✔️, and ☑️ come up when you search check. For the plain text ✓, click the expand button to open the full Character Viewer and search there. More on the picker in How to type emoji on a Mac.

What’s the HTML code for a check mark?

&check; or &#10003; for ✓. The heavy ✔ has no named entity, so use &#10004;. The ✗ is &cross; or &#10007;. In CSS content, a ✓ is "\2713".

Is a tick the same thing as a check mark?

Yes. British English calls it a tick, American English a check mark; it’s the same character, U+2713. That’s why Mojito answers to both ::tick and ::check_mark.

How do I type a check mark on Windows?

Press Win + . and look under Symbols. Watch out for the often-quoted Alt + 251: like ⌥V on a Mac, it types √.
